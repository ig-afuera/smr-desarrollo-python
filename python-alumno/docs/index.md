Todas las soluciones están incluidas, pero **ocultas**. Despliégalas solo después de haberlo intentado:

    comprueba que hace lo que pide el enunciado. Casi siempre hay varias formas correctas de resolver un problema.

## Consejos para estudiar programación

!!! tip "Programar se aprende programando"
    - **Escribe** los ejemplos tú mismo en lugar de copiarlos y pegarlos.
    - **Cámbialos** y observa qué pasa. Rompe el código a propósito para ver qué error da.
    - **Lee los errores**: Python te dice qué ha fallado y en qué línea. Es la mejor pista que tendrás.
    - Si llevas más de 15 minutos atascado/a, mira la solución, **entiéndela**, cierra la página y vuelve a escribirla de memoria.

## Convenciones de estos apuntes

- Las líneas que empiezan por `>>>` se escriben en la **consola de Python (REPL)**. No escribas el `>>>`; Python lo muestra solo.
- Las líneas **sin** `>>>` que aparecen justo debajo son lo que Python responde.
- Los bloques de código sin `>>>` son programas completos (o trozos de programa) para guardar en un archivo `.py` o escribir en una celda de Jupyter.

- Los cuadros de colores destacan información: **nota** (complemento), **consejo** (un truco para trabajar mejor),
  **atención** (un error muy frecuente) y **ejemplo** (un caso práctico resuelto).
