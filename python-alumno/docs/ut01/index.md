# UT01. Identificación de los elementos de un programa informático

## ¿Qué vas a aprender?

Al terminar esta unidad serás capaz de:

- Explicar qué es un programa y cuáles son las fases de su desarrollo.
- Preparar tu entorno de trabajo y ejecutar código con la **consola de Python**, **Visual Studio Code** y **Jupyter Notebook**.
- Reconocer la estructura de un programa en Python: sentencias, bloques e indentación.
- Declarar **variables** con nombres correctos y elegir el **tipo de dato** adecuado.
- Escribir **literales** y **constantes**.
- Construir **expresiones** con operadores y saber en qué orden se evalúan.
- **Convertir** datos de un tipo a otro.
- Documentar tu código con **comentarios** y *docstrings*.
