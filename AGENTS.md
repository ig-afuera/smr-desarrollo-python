# AGENTS.md — SMR-Desarrollo-Python

## Proyecto
Se trata de un repositorio que sirve de ayuda al docente en la asignatura de desarrollo con Python.

## Rutas importantes
- Todas las rutas que se indican a continuación son relativas a la raiz de este proyecto.
- python-alumno: mkdocs que se usa para el seguimiento de las clases (actividades, teoria)
- python-profesor: material de apoyo al profesor (actividades, examenes, etc)
- python-alumno/docs: donde vive la teoria y actividades que se usan para los alumnos.

## Estilo y convenciones
- Todo el código que se anote de ejemplo en la teoria sigue el estandar PEP8.
- Dentro de la carpeta docs el contenido esta separado en carpetas por **unidades de trabajo** (ut01, ut02, etc)
- El contenido debe de acompañarse de ejemplos de código
- Tambien se pueden usar imagenes para acompañar el contenido. Siempre las imagenes deben de estar creadas por el agente. Nunca las tomes de internet sin permiso.
- El contenido de la carpeta del profesor debe de ser diferente al expuesto en la carpeta del alumno
- Ejemplos y preguntas usadas en el contenido del alumno no se parecen en nada a las de la carpeta del profesor.

## Reglas
- No instales nuevas librerias sin antes preguntar

## Al terminar cualquier tarea
- Presenta un reporte al usuario y pide confirmacion antes de realizar ningun commit

## Commits del proyecto
- No se debe de incluir coautor.
- Commits lo mas atomicos posibles, es decir. Un commit: una cosa o un commit una funcionalidad.
- A la hora de preparar un commit no se editan los ficheros. Apañate con la suite de comandos que proporciona git.
